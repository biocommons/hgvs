Changes since 1.5.

Breaking Changes
$$$$$$$$$$$$$$$$$

* Data provider interface version 5: ``Interface.get_tx_info`` returns a
  :class:`hgvs.dataproviders.models.TranscriptInfo` instead of a dict.
  Read fields as attributes (``tx_info.cds_start_i``). Data providers
  written against interface version 4 can be used unchanged by wrapping
  them with the bridge: ``hdp = Interface.from_v4(provider)``.
